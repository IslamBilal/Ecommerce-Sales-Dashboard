# E-Commerce Sales Dashboard | Power BI

An interactive e-commerce sales analysis dashboard built with **Microsoft Power BI**. The project is intended to help explore sales performance and turn business data into clear, actionable insights.

## Project Overview

This repository contains the Power BI dashboard project for analyzing e-commerce sales data. Open the `.pbix` file in Power BI Desktop to explore the report and its interactive visuals.

## Tools & Technologies

- **Microsoft Power BI** – dashboard development and data visualization
- **Power Query** – data import and transformation (where used in the report)
- **DAX** – measures and calculations (where used in the report)

## Getting Started

1. Download the `.pbix` file from this repository.
2. Install and open **Power BI Desktop**.
3. Open the downloaded `.pbix` file.
4. Use the report filters and visual interactions to explore the dashboard.

## Project Files

- `Ecommerce-Dashboard.pbix` – Power BI report file.
